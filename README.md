One post on X promoting make.fun's make-your-own-bounty launch: it quote-posts @makefunai's announcement with an original photo (photo.png), carries the line "Make your own bounty on @makefunai: https://make.fun/sponsor/new" and the entrant's play code, and is ranked by its replies, reposts and quotes. POST.json names the post; main.ts copies POST.json into the output directory for the gate. Note: POST.json currently holds a placeholder address — it is replaced with the real post's address once the post is published.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
